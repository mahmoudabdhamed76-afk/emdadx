# إمداد إكس — نظام إدارة التوريدات والمحاسبة

**الإصدار 4.1 · بتصميم My Life**

نظام إدارة متكامل لشركة توريدات ورق وأفلام: صرف الورق للمراكز، الفواتير، التحصيل، الموردين، المخازن، المصروفات والتقارير — مع مزامنة لحظية بين كل الأجهزة وتشغيل كامل بدون إنترنت.

- **بدون أي مكتبات خارجية**: Node.js 22+ فقط (`node:sqlite` + `node:http`) — مفيش `npm install`.
- **يشتغل أوف لاين بالكامل**: الخطوط ومكتبة الرسوم البيانية موجودين داخل المشروع، والبيانات بتتحفظ محلياً وتتزامن أول ما النت يرجع.
- **مزامنة لحظية** بين الكمبيوتر والموبايل (Server-Sent Events).

---

## الجديد في الإصدار 4.1

**نفس خطوط وشكل وألوان برنامج My Life**
- خط Zain للعناوين والأرقام الكبيرة، و IBM Plex Sans Arabic لباقي الواجهة.
- ألوان أبيض وأسود نضيفة (ورقي فاتح بالنهار — أسود بالليل)، والألوان بس في أيقونات الأقسام بدرجات هادية.
- كروت بزوايا دائرية وظل ناعم من غير حدود، وأزرار سودا (بيضا في الوضع الليلي)، وحقول رمادي مليانة.
- هيدر أسود بزوايا مدورة على الموبايل، والقسم المختار في القائمة بيبقى كبسولة سودا.

## الجديد في الإصدار 4.0

**شكل جديد بالكامل**
- وضع ليلي ووضع نهاري حقيقي (زرار القمر/الشمس فوق).
- قائمة جانبية هادئة، وتقدر تصغّرها لشريط أيقونات (الزرار جنب اللوجو).
- كروت وجداول ونماذج بتصميم موحد في كل الصفحات.
- شاشة دخول جديدة.

**مميزات جديدة**
- **ملخص يومك** أعلى لوحة التحكم: مبيعات اليوم، تحصيل اليوم، صرف الورق، صافي الخزنة، والتاريخ الميلادي والهجري.
- **هدف مبيعات الشهر**: حدد رقم، والبرنامج يعرض نسبة التحقيق والمطلوب يومياً لآخر الشهر.
- **تقفيل اليومية**: تقرير اليوم كامل (المبيعات، التحصيل حسب طريقة الدفع، المصروفات، الكميات المصروفة حسب النوع، المراكز) + طباعة A4 بهوية الشركة.
- **تقويم التحصيل**: كل المستحقات على العملاء والموردين في تقويم شهري، والمتأخر باللون الأحمر، وتحصّل من اليوم مباشرة.
- **زرار الإنشاء السريع (+)** في شريط الموبايل: فاتورة، صرف ورق، تحصيل، عميل، مصروف، تقفيل، سداد لمورد.

**إصلاحات**
- تاريخ "النهارده" بقى بتوقيت الجهاز (قبل كده العمليات بعد نص الليل كانت بتتسجل على اليوم اللي فات).
- التحديثات بتظهر فوراً بعد النشر (Service Worker بقى يجيب الصفحة من السيرفر الأول).

## التشغيل على الكمبيوتر

**ويندوز:** دبل كليك على `START.bat` — هيفتح المتصفح على `http://localhost:8787`

**ماك / لينكس:**
```bash
chmod +x START.sh && ./START.sh
```

**يدوياً:**
```bash
APP_PATH= node backend/server.js
```

الدخول الافتراضي: `admin` / `admin` — غيّره من صفحة المستخدمين.

## النشر على Railway

1. ارفع المشروع على GitHub واربطه بـ Railway (بيشتغل بـ Nixpacks تلقائياً).
2. في **Variables** ضيف:
   - `APP_PATH` = فاضي
   - `DATA_DIR` = `/app/data`
3. اربط **Volume** على المسار `/app/data` عشان البيانات متتمسحش مع كل تحديث.

> لو إنت ناشر قبل كده: اعمل Push للملفات الجديدة بس — قاعدة البيانات (`data/ozarex.db`) مش جزء من الريبو، وبياناتك هتفضل زي ما هي.

## هيكل المشروع

```
backend/
  server.js          السيرفر + API + المزامنة اللحظية
  db/                قاعدة البيانات (SQLite) والجداول
  src/bridge.js      تحويل البيانات بين الواجهة والجداول
frontend/public/
  index.html         التطبيق
  css/aurum.css      نظام التصميم (خطوط وألوان My Life، الوضع الليلي/النهاري، المكونات)
  js/aurum.js        المميزات الجديدة (ملخص اليوم، الهدف، التقفيل، التقويم، الإنشاء السريع)
  fonts/             الخطوط (تعمل بدون إنترنت)
  vendor/            Chart.js ومكتبة لقطات الشاشة
  sw.js              التشغيل بدون إنترنت
data/                قاعدة البيانات (تتنشأ تلقائياً — مش بتترفع على GitHub)
```
